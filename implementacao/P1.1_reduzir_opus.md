# P1.1 — Reduzir uso de Opus para tarefas que não exigem

**Prioridade:** P1
**Tipo:** feat
**Branch:** `feat/p1-1-reduzir-opus`
**Esforço estimado:** 2-3 dias
**Depende de:** P0.3 (telemetria — para validar redução de custo com dados reais)

## Objetivo

Migrar agentes que executam tarefas determinísticas ou de baixa complexidade do Claude Opus 4.6 para modelos mais baratos. Estimativa: corte de 50-65% no custo de tokens por orçamento sem perda perceptível de qualidade.

## Contexto

5 dos 10 agentes rodam em Opus hoje:

| Agente | Modelo atual | Tarefa | Modelo proposto | Justificativa |
|---|---|---|---|---|
| Engenheiro Técnico | Opus | Inferência de specs + extração de itens | **Manter Opus** | Trabalho criativo com tabelas de inferência, alta variabilidade nos memoriais |
| Orçamentista | Opus | Precificação com âncoras + curva A/C | **Manter Opus** | Decisões financeiras críticas, anchor system reduz alucinação mas não elimina |
| Tributário | Opus | Classificação ISS/ICMS + cálculo de alíquotas | **Sonnet 4.6** | Tabela de alíquotas embutida + regras simples; Sonnet basta |
| Jurídico | Opus | Redação contratual | **Sonnet 4.6** | Templating com slots — não precisa de Opus (será reformulado em P1.6) |
| Board | Opus | Decisão executiva sobre cálculos pré-feitos | **Sonnet 4.6** | Margem já vem calculada, só decide e justifica |

Comercial (Gemini Flash) e Financeiro (Gemini Flash) são tratados em **P1.2** (viram funções determinísticas).

Migração só vale se a qualidade não cair. Por isso o ticket exige **suite de regressão** com casos comparáveis.

## Estimativa de impacto financeiro

Com base nos volumes do diagnóstico (Reforma Vânia, médio):

| Agente | Tokens (in+out) | Custo Opus | Custo Sonnet | Economia |
|---|---|---|---|---|
| Tributário | ~7.600 | ~R$ 0,79 | ~R$ 0,16 | R$ 0,63 (-80%) |
| Jurídico | ~5.150 | ~R$ 2,10 | ~R$ 0,42 | R$ 1,68 (-80%) |
| Board | ~5.000 | ~R$ 1,46 | ~R$ 0,29 | R$ 1,17 (-80%) |
| **Total** | | **R$ 4,35** | **R$ 0,87** | **R$ 3,48 (-80%)** |

Para um orçamento médio, a redução é de aproximadamente R$ 3,50. Em volume de 100 orçamentos/mês, economia mensal de R$ 350. Em volume de 1.000/mês (potencial em 18 meses), R$ 3.500/mês.

(Valores nos cálculos acima usam FX R$ 5,20/USD e premissa de input/output 50/50 — ajustar com dados reais de P0.3 após coleta.)

## Testes

Estrutura sugerida de regressão:

```ts
// server/agents-regression.test.ts
import casos from './agents/__regression__/casos.json';

const SHOULD_RUN_REGRESSION = process.env.RUN_REGRESSION === '1';

describe.skipIf(!SHOULD_RUN_REGRESSION)('Regressão Tributário', () => {
  for (const caso of casos.tributario) {
    it(caso.id, async () => {
      const out = await agents.tributario.execute(caso.input);
      expect(out.classifiedItems.length).toBeGreaterThan(0);
      const ratio = out.totalTaxes / caso.input.budgetItems.reduce((s, i) => s + i.totalCost * i.quantity, 0);
      expect(ratio).toBeGreaterThanOrEqual(caso.expectedTaxRange[0]);
      expect(ratio).toBeLessThanOrEqual(caso.expectedTaxRange[1]);
    }, 60_000);
  }
});
```

A flag `RUN_REGRESSION=1` evita que o CI execute regressão a toda hora — ela é cara em tokens. Roda manualmente quando há mudança de modelo ou em cron noturno.

## Observações

- Em caso de regressão de qualidade detectada após o merge, a reversão é trivial: voltar para `claude-opus-4-6` no agente afetado. A telemetria de P0.3 vai registrar a mudança e permitir comparação.
- Se um agente específico mostrar piora consistente em Sonnet (ex.: Jurídico produzindo cláusulas com falhas formais), considerar Sonnet com extended thinking habilitado em vez de fallback para Opus. Custo similar a Sonnet sem thinking.
- Esta tarefa é executada **antes** de P1.6 (templating Jurídico) intencionalmente — primeiro reduz custo, depois reformula. Se P1.6 for executado primeiro, o Jurídico pode até ser elegível para Haiku 4.5.
