# P2.3 — Minificar JSON em user prompts

**Prioridade:** P2
**Tipo:** chore
**Branch:** `chore/p2-3-minify-json`
**Esforço estimado:** 0,5 dia
**Depende de:** —

## Objetivo

Substituir todas as ocorrências de `JSON.stringify(x, null, 2)` em user prompts por `JSON.stringify(x)` (sem indentação). Indentação consome tokens à toa — economia estimada de 12-18% nos prompts dos agentes Board, Orçamentista, Tributário, Logística e Auditor.

## Contexto

Vários agentes em `server/agents/index.ts` enviam payload JSON formatado com indentação:

```ts
ITENS DA OBRA:
${JSON.stringify(input.items, null, 2)}
```

A indentação é útil para humanos lerem o prompt num log. A LLM lê igualmente JSON minificado, e cobra por cada token de espaço/quebra de linha.

Cálculo rápido: um array com 100 itens em JSON com `null, 2` ocupa cerca de 22.000 tokens. Em JSON minificado (sem espaços além do necessário), ocupa cerca de 18.500 tokens — corte de 16%.

Em obra média, isso representa economia de R$ 0,30-0,80 por orçamento sem nenhum impacto na qualidade. Em volume de 1.000 orçamentos/mês, R$ 300-800/mês.

## Arquivos a tocar

- `server/agents/index.ts` — substituir todas as ocorrências em `getUserPrompt`
- `server/agents.test.ts` — confirmar que prompts continuam contendo os mesmos campos
- (Opcional) `server/utils/promptHelpers.ts` (novo) — helper `compactJson(obj)` que centraliza a serialização

- [ ] Criar `server/utils/promptHelpers.ts`:
  ```ts
  /**
   * Serializa objeto para inclusão em user prompt.
   * Sem indentação. Reduz consumo de tokens em ~15%.
   */
  export function compactJson(obj: unknown): string {
    return JSON.stringify(obj);
  }

  /**
   * Versão para debugging — usa indentação. Para logs, não para prompts.
   */
  export function readableJson(obj: unknown): string {
    return JSON.stringify(obj, null, 2);
  }
  ```

## Testes

Teste rápido no helper:

```ts
import { describe, it, expect } from 'vitest';
import { compactJson, readableJson } from './utils/promptHelpers';

describe('promptHelpers', () => {
  it('compactJson não tem indentação', () => {
    const out = compactJson({ a: 1, b: [2, 3] });
    expect(out).toBe('{"a":1,"b":[2,3]}');
  });

  it('compactJson é menor que readable', () => {
    const obj = { items: Array.from({ length: 50 }, (_, i) => ({ id: i, name: `item ${i}` })) };
    expect(compactJson(obj).length).toBeLessThan(readableJson(obj).length);
  });
});
```

## Observações

- Trabalho mecânico — pode ser feito por search-and-replace e revisão de PR.
- Manter `JSON.stringify(x, null, 2)` em mensagens de erro/log que vão para console é OK — esses não vão para LLM.
- Se algum prompt tem comentários inline tipo `// resumo do agente`, remover também — não agregam valor para LLM.
