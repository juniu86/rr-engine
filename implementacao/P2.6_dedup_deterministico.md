# P2.6 — Dedup determinístico no Auditor

**Prioridade:** P2
**Tipo:** feat
**Branch:** `feat/p2-6-dedup-deterministico`
**Esforço estimado:** 2-3 dias
**Depende de:** P0.4 (chunking do Auditor), P1.3 (utilitários de dedup)

## Objetivo

Substituir a detecção de duplicatas via LLM no Auditor por um algoritmo determinístico construído sobre `dedupItems` de P1.3. A LLM continua tendo papel narrativo (gerar `auditNotes`), mas a decisão sobre o que é duplicata vira código auditável.

## Contexto

`AuditorAgent.getSystemPrompt()` em `server/agents/index.ts` instrui:

> VERIFIQUE se há itens duplicados no orçamento:
> 1. Itens com descrição idêntica ou muito similar (>80% de sobreposição textual)
> ...
> Se encontrar duplicatas, liste-as no campo "corrections"

Esse trabalho é determinístico por natureza — sobreposição textual é uma medida calculável. Em P1.3 já temos `tokenSimilarity()` e `dedupItems()`. Esta tarefa pluga isso no Auditor.

Vantagens:
- Decisão auditável: dado o mesmo input, mesma resposta.
- Custo zero por orçamento na parte de dedup.
- Permite ajustar threshold sem retreinar/reformular prompt.
- LLM continua útil para parte qualitativa (`auditNotes`, `crossAgentChecks`, validações que exigem inferência).

## Arquivos a tocar

- `server/agents/dedupUtils.ts` — extender com função específica para Auditor
- `server/agents/index.ts` — `AuditorAgent.execute()` (override) chama dedup antes/depois da LLM
- `server/auditor-dedup.test.ts` (novo)

## Implementação proposta

```ts
// server/agents/dedupUtils.ts (estender)

import type { BudgetItemDetail } from '../../shared/agents';

export interface DuplicateFinding {
  description: string;
  reason: string;
  estimatedImpact: number;
  similarItem?: { description: string; quantity: number; unit: string };
}

/**
 * Detecta duplicatas no orçamento e retorna no formato
 * de corrections.budgetItemsToRemove esperado pelo Auditor.
 */
export function findBudgetDuplicates(items: BudgetItemDetail[]): DuplicateFinding[] {
  const result = dedupItems(items as any[], { strictThreshold: 0.85, suspectThreshold: 0.65 });
  const findings: DuplicateFinding[] = [];

  for (const removal of result.duplicatesRemoved) {
    if (removal.reason === 'suspect_only_logged') continue; // não inclui suspeitas

    const removed = items[removal.removedIndex];
    const keeper = items[removal.keeperIndex];

    findings.push({
      description: removed.description,
      reason: removal.reason === 'exact_match'
        ? `Duplicata exata de "${keeper.description}"`
        : `Alta similaridade (${(removal.similarity * 100).toFixed(0)}%) com "${keeper.description}"`,
      estimatedImpact: (removed.quantity ?? 0) * (removed.unitCostTotal ?? 0),
      similarItem: {
        description: keeper.description,
        quantity: keeper.quantity,
        unit: keeper.unit,
      },
    });
  }

  return findings;
}

/**
 * Detecta itens-pai (isSummaryItem=true) que tem custo > 0 — devem estar a 0.
 */
export function findInvalidSummaryItems(items: BudgetItemDetail[]): DuplicateFinding[] {
  return items
    .filter(i => (i as any).isSummaryItem && i.totalCost > 0)
    .map(i => ({
      description: i.description,
      reason: 'Item PAI (isSummaryItem=true) com custo diferente de zero — somar com filhos é duplicação',
      estimatedImpact: i.totalCost,
    }));
}
```

## Override do `AuditorAgent.execute()`

```ts
async execute(input: AuditorInput): Promise<AuditorOutput> {
  // 1. Dedup determinístico ANTES de chamar LLM
  const items = input.allAgentOutputs?.orcamentista?.budgetItems ?? [];
  const duplicates = [
    ...findBudgetDuplicates(items),
    ...findInvalidSummaryItems(items),
  ];
  const totalImpact = duplicates.reduce((s, d) => s + d.estimatedImpact, 0);

  // 2. Adicionar pré-cálculo ao input para a LLM saber o que já foi detectado
  const inputComDedup = {
    ...input,
    _preComputed: {
      duplicates,
      duplicatesTotalImpact: totalImpact,
    },
  };

  // 3. LLM faz validações matemáticas e gera auditNotes
  const llmOutput = await super.execute(inputComDedup as any);

  // 4. Sobrescrever corrections.budgetItemsToRemove com o que o algoritmo achou
  const finalOutput: AuditorOutput = {
    ...llmOutput,
    corrections: {
      budgetItemsToRemove: duplicates.map(d => ({
        description: d.description,
        reason: d.reason,
        estimatedImpact: d.estimatedImpact,
      })),
      logisticsToRemove: llmOutput.corrections?.logisticsToRemove ?? [],
      totalImpact: totalImpact + (llmOutput.corrections?.logisticsToRemove?.reduce((s, l) => s + l.estimatedImpact, 0) ?? 0),
      correctedDirectCost: (input.allAgentOutputs.orcamentista?.totalDirectCost ?? 0) - totalImpact,
      correctedLogisticsCost: (input.allAgentOutputs.logistica?.totalLogisticsCost ?? 0) - (llmOutput.corrections?.logisticsToRemove?.reduce((s, l) => s + l.estimatedImpact, 0) ?? 0),
    },
  };

  return finalOutput;
}
```

## Atualização do prompt

Adicionar no `getSystemPrompt`:

```
=== ATUALIZAÇÃO IMPORTANTE ===
A detecção de duplicatas no orçamento é feita ANTES desta chamada por algoritmo determinístico.
Você recebe em _preComputed.duplicates a lista já identificada.
Sua tarefa NÃO é detectar duplicatas — é validar matematicamente o resto e gerar auditNotes
sobre as duplicatas já detectadas.

NÃO sobrescreva corrections.budgetItemsToRemove — o caller fará isso após sua resposta.
```

## Testes

`server/auditor-dedup.test.ts`:

```ts
import { describe, it, expect } from 'vitest';
import { findBudgetDuplicates, findInvalidSummaryItems } from './agents/dedupUtils';

describe('findBudgetDuplicates', () => {
  it('detecta duplicata exata', () => {
    const items = [
      { description: 'Pintura acrílica', unit: 'm²', quantity: 50, unitCostTotal: 30, totalCost: 1500 },
      { description: 'pintura acrilica', unit: 'm²', quantity: 50, unitCostTotal: 30, totalCost: 1500 },
    ];
    const findings = findBudgetDuplicates(items as any);
    expect(findings).toHaveLength(1);
    expect(findings[0].estimatedImpact).toBe(1500);
  });

  it('não detecta itens diferentes da mesma categoria', () => {
    const items = [
      { description: 'Tomada elétrica simples', unit: 'un', quantity: 10, totalCost: 50, category: 'Elétrica' },
      { description: 'Tomada elétrica USB', unit: 'un', quantity: 5, totalCost: 75, category: 'Elétrica' },
    ];
    expect(findBudgetDuplicates(items as any)).toHaveLength(0);
  });
});

describe('findInvalidSummaryItems', () => {
  it('detecta item PAI com custo > 0', () => {
    const items = [
      { description: 'Sistema VRF completo', isSummaryItem: true, totalCost: 75_000 },
      { description: 'Condensadora VRF', isSummaryItem: false, totalCost: 35_000 },
    ];
    const findings = findInvalidSummaryItems(items as any);
    expect(findings).toHaveLength(1);
    expect(findings[0].estimatedImpact).toBe(75_000);
  });
});
```

## Observações

- Manter um modo opcional via env (`AUDITOR_USE_LLM_DEDUP=true`) para comparar resultados em paralelo durante 30 dias antes de remover totalmente o caminho LLM. Permite calibrar thresholds.
- Após estabilizar, considerar extender o algoritmo para detectar:
  - Itens com descrição diferente mas mesma composição (ex.: SINAPI 87529 vs descrição livre que aponta para o mesmo serviço).
  - Itens com custo unitário absurdamente alto comparado a itens da mesma categoria (outlier detection).
- A função `findBudgetDuplicates` é reutilizável fora do Auditor — pode ser exposta em uma futura UI de revisão manual.
