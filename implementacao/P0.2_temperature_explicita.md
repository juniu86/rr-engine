# P0.2 — Temperature explícita por agente

**Prioridade:** P0
**Tipo:** feat
**Branch:** `feat/p0-2-temperature-explicita`
**Esforço estimado:** 0,5 dia
**Depende de:** P0.5 (CI)

## Objetivo

Setar `temperature` explícita em cada agente, com valor adequado à natureza da tarefa. Sem isso, o sistema herda o default do provider (~1.0), e duas execuções do mesmo memorial podem produzir orçamentos com valores diferentes — produto não-reproduzível.

## Contexto

Em `server/agents/index.ts`, o método `_execute()` chama `invokeLLM()` sem passar `temperature`. Em `server/_core/llm.ts`, o payload é construído sem temperatura. Logo, todos os 10 agentes operam em temperatura default do provider.

A solução é introduzir um método `getTemperature()` no `BaseAgent` (com valor padrão sensato) e permitir override por agente. O valor entra no payload de `invokeLLM()` e é repassado ao Forge/Anthropic.

## Distribuição proposta

| Agente | Temperatura | Justificativa |
|---|---|---|
| Engenheiro Técnico | 0.3 | Inferência de specs precisa de alguma criatividade controlada para mapear padrões de qualidade |
| Logística | 0.2 | Cálculo de custos indiretos com referências numéricas — pouca variação |
| Orçamentista | 0.1 | Precificação direta com âncoras SINAPI/PINI — quase determinístico |
| Tributário | 0.0 | Classificação fiscal e aplicação de alíquotas — totalmente determinístico |
| Comercial | 0.0 | Multiplicação BDI — determinístico (será removido em P1.2) |
| Gestão de Projetos | 0.3 | Cronograma exige alguma criatividade na sequência de atividades |
| Financeiro | 0.0 | Recebe cashflow pré-calculado — só repassa (será removido em P1.2) |
| Jurídico | 0.4 | Redação contratual exige alguma fluência (será trocado por templating em P1.6) |
| Board | 0.2 | Decisão executiva com critérios numéricos rígidos |
| Auditor | 0.0 | Validação matemática pura |

## Implementação detalhada — alteração no `_core/llm.ts`

Localizar `InvokeParams` (~linha 60) e adicionar:

```ts
export type InvokeParams = {
  model?: string;
  messages: Message[];
  tools?: Tool[];
  toolChoice?: ToolChoice;
  tool_choice?: ToolChoice;
  maxTokens?: number;
  max_tokens?: number;
  /** Temperatura. Se omitida, usa 0.2 como default conservador. */
  temperature?: number;
  outputSchema?: OutputSchema;
  output_schema?: OutputSchema;
  responseFormat?: ResponseFormat;
  response_format?: ResponseFormat;
};
```

No corpo de `invokeLLM`, antes do `fetch` à Forge:

```ts
payload.temperature = params.temperature ?? 0.2;
```

Atenção ao caminho da Anthropic direta (`invokeAnthropicDirect`) — passar a temperatura também naquele payload.

## Implementação detalhada — alteração no `BaseAgent`

Localizar a classe `BaseAgent` e adicionar:

```ts
abstract class BaseAgent<TInput, TOutput> {
  // ... métodos existentes

  getPreferredModel(): string {
    return process.env.LLM_MODEL ?? "gemini-2.5-flash";
  }

  getTemperature(): number {
    return 0.2;
  }

  // ... _execute()
}
```

No `_execute()`, encontrar a chamada `invokeLLM({ ... })` e adicionar:

```ts
response = await invokeLLM({
  model: preferredModel,
  temperature: this.getTemperature(),
  messages: [ /* ... */ ],
  response_format: { /* ... */ },
});
```

Em cada uma das 10 classes de agente, adicionar override próximo a `getPreferredModel()`:

```ts
export class EngenheiroTecnicoAgent extends BaseAgent<...> {
  getPreferredModel() { return process.env.LLM_MODEL_CRITICAL ?? "claude-opus-4-6"; }
  getTemperature() { return 0.3; }
  // ...
}
```

```ts
import { describe, it, expect, vi } from 'vitest';
import { invokeLLM } from './_core/llm';

describe('invokeLLM temperature', () => {
  it('passes temperature to forge payload', async () => {
    const fetchSpy = vi.spyOn(global, 'fetch').mockResolvedValue(
      new Response(JSON.stringify({ choices: [{ message: { content: '{}' }, finish_reason: 'stop' }] }))
    );

    await invokeLLM({
      model: 'gemini-2.5-flash',
      temperature: 0.5,
      messages: [{ role: 'user', content: 'test' }],
    });

    const body = JSON.parse(fetchSpy.mock.calls[0][1]?.body as string);
    expect(body.temperature).toBe(0.5);
    fetchSpy.mockRestore();
  });

  it('defaults to 0.2 when temperature omitted', async () => {
    const fetchSpy = vi.spyOn(global, 'fetch').mockResolvedValue(
      new Response(JSON.stringify({ choices: [{ message: { content: '{}' }, finish_reason: 'stop' }] }))
    );

    await invokeLLM({
      model: 'gemini-2.5-flash',
      messages: [{ role: 'user', content: 'test' }],
    });

    const body = JSON.parse(fetchSpy.mock.calls[0][1]?.body as string);
    expect(body.temperature).toBe(0.2);
    fetchSpy.mockRestore();
  });
});
```
