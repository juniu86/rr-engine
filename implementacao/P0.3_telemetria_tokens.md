# P0.3 — Persistir tokens consumidos por orçamento

**Prioridade:** P0
**Tipo:** feat
**Branch:** `feat/p0-3-telemetria-tokens`
**Esforço estimado:** 1-2 dias
**Depende de:** P0.5 (CI)

## Objetivo

Registrar em banco cada chamada a `invokeLLM` com agente, modelo, prompt_tokens, completion_tokens, custo estimado em USD e BRL, latência. Sem isso, "quanto custou o orçamento X" não tem resposta — e qualquer decisão de pricing fica sem base.

## Contexto

`invokeLLM` em `server/_core/llm.ts` retorna `usage: { prompt_tokens, completion_tokens, total_tokens }` quando o provider devolve. Hoje esse campo é ignorado. `server/utils/logger.ts` é só winston/console — não persiste nada. Consequência: o sistema gerou 29 projetos até janeiro/2026 e não temos ideia de quanto consumiu.

A solução é uma tabela `agent_executions` no banco, populada via wrapper em torno de `invokeLLM` que extrai `usage` e calcula custo com tabela de preços por modelo.

## Tabela de preços (`llm-pricing.ts`)

```ts
// Preços em USD por milhão de tokens (1 Mtok). Atualizar quando providers mudarem tabela.
// Última atualização: 2026-05-04

export interface ModelPricing {
  inputPerMtok: number;  // USD
  outputPerMtok: number; // USD
}

export const MODEL_PRICING: Record<string, ModelPricing> = {
  'claude-opus-4-6':    { inputPerMtok: 15.00, outputPerMtok: 75.00 },
  'claude-sonnet-4-6':  { inputPerMtok:  3.00, outputPerMtok: 15.00 },
  'claude-haiku-4-5':   { inputPerMtok:  1.00, outputPerMtok:  5.00 },
  'gemini-2.5-flash':   { inputPerMtok:  0.30, outputPerMtok:  2.50 },
  'gemini-2.5-pro':     { inputPerMtok:  1.25, outputPerMtok: 10.00 },
  'gpt-4o':             { inputPerMtok:  2.50, outputPerMtok: 10.00 },
  'gpt-4o-mini':        { inputPerMtok:  0.15, outputPerMtok:  0.60 },
};

export const FX_USD_BRL = parseFloat(process.env.FX_USD_BRL ?? '5.20');

export function estimateCost(
  model: string,
  promptTokens: number,
  completionTokens: number,
): { usd: number; brl: number } {
  const pricing = MODEL_PRICING[model] ?? { inputPerMtok: 1, outputPerMtok: 5 };
  const usd =
    (promptTokens / 1_000_000) * pricing.inputPerMtok +
    (completionTokens / 1_000_000) * pricing.outputPerMtok;
  const brl = usd * FX_USD_BRL;
  return { usd, brl };
}
```

## Wrapper de telemetria (`server/services/llmTelemetry.ts`)

```ts
import { db } from '../db';
import { agentExecutions } from '../../drizzle/schema';
import { estimateCost } from '../_core/llm-pricing';
import { logger } from '../utils/logger';
import type { AgentType } from '../../shared/agents';

export interface ExecutionRecord {
  projectId: number;
  agentType: AgentType;
  model: string;
  promptTokens: number;
  completionTokens: number;
  totalTokens: number;
  latencyMs: number;
  finishReason?: string | null;
  attemptNumber?: number;
  errorMessage?: string | null;
}

export async function recordExecution(record: ExecutionRecord): Promise<void> {
  try {
    const { usd, brl } = estimateCost(
      record.model,
      record.promptTokens,
      record.completionTokens,
    );

    await db.insert(agentExecutions).values({
      projectId: record.projectId,
      agentType: record.agentType,
      model: record.model,
      promptTokens: record.promptTokens,
      completionTokens: record.completionTokens,
      totalTokens: record.totalTokens,
      costUsd: usd.toFixed(6),
      costBrl: brl.toFixed(4),
      latencyMs: record.latencyMs,
      finishReason: record.finishReason ?? null,
      attemptNumber: record.attemptNumber ?? 1,
      errorMessage: record.errorMessage ?? null,
    });
  } catch (err) {
    // Telemetria nunca pode quebrar o pipeline. Só loga.
    logger.error('Failed to persist agent execution', { error: err, record });
  }
}
```

## Testes

`server/llm-telemetry.test.ts`:

```ts
import { describe, it, expect } from 'vitest';
import { estimateCost, FX_USD_BRL } from './_core/llm-pricing';

describe('estimateCost', () => {
  it('calcula custo Opus corretamente', () => {
    const { usd } = estimateCost('claude-opus-4-6', 10_000, 5_000);
    // 10k * 15/1M + 5k * 75/1M = 0.15 + 0.375 = 0.525
    expect(usd).toBeCloseTo(0.525, 4);
  });

  it('calcula custo Gemini Flash corretamente', () => {
    const { usd } = estimateCost('gemini-2.5-flash', 100_000, 50_000);
    // 100k * 0.30/1M + 50k * 2.50/1M = 0.03 + 0.125 = 0.155
    expect(usd).toBeCloseTo(0.155, 4);
  });

  it('aplica FX para BRL', () => {
    const { usd, brl } = estimateCost('gemini-2.5-flash', 100_000, 50_000);
    expect(brl).toBeCloseTo(usd * FX_USD_BRL, 4);
  });

  it('usa fallback conservador para modelo desconhecido', () => {
    const { usd } = estimateCost('modelo-inventado', 1_000_000, 1_000_000);
    expect(usd).toBeGreaterThan(0);
  });
});
```

## Observações

- O `invokeLLM` atual nem sempre garante que `usage` venha populado (depende do provider). Tratar `usage = undefined` como zero e logar warning.
- Custo em BRL é estimativa — usa FX configurado em env. Para precisão financeira, esse número não vale para fechamento contábil; serve para análise de unit economics interna.
- Após coletar 30 dias de dados, abrir issue para revisar tabela de preços e comparar gasto real (faturas Anthropic/Google) com o registrado — corrigir desvios.
- A tabela vai crescer rápido (10 inserts por orçamento). Considerar estratégia de retenção ou agregação após 6 meses, mas só depois de validar que os dados servem para análise.
