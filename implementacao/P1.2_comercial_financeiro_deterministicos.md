# P1.2 — Comercial e Financeiro determinísticos

**Prioridade:** P1
**Tipo:** feat
**Branch:** `feat/p1-2-comercial-financeiro-deterministicos`
**Esforço estimado:** 3-4 dias
**Depende de:** P0.3 (telemetria — para confirmar custo zero pós-migração)

## Objetivo

Substituir os agentes Comercial e Financeiro por funções TypeScript puras. Ambos executam tarefas que não exigem LLM:

- **Comercial** aplica `precoFinal = custoBase × (1 + bdiAjustado)` — multiplicação direta com ajustes condicionais.
- **Financeiro** recebe um cashFlow já calculado deterministicamente pelo backend e devolve "alertas qualitativos" — pode virar regras de negócio em código.

Mantém-se a interface dos outputs (mesmo schema), trocando-se a implementação por código puro. Opcionalmente, um agente "narrador" continua gerando alertas em texto, mas em modelo barato (Haiku) e apenas em cima dos dados já decididos por código.

## Contexto

### Comercial (atual)

System prompt diz literalmente:

> FÓRMULA OBRIGATÓRIA:
> - BDI BASE: ${effectiveBdi}%
> - Preço Final = Custo Base × (1 + BDI)

Ajustes documentados:
- Risco fiscal alto: +5%
- Complexidade logística alta: +5%
- Cliente recorrente: -5% (não acessado pelo input atual)
- Prazo apertado: +10% (não acessado pelo input atual)

Saída inclui `bdiJustification` em texto livre. Esse é o único campo que se beneficia de LLM. Pode ser gerado por template ou por agente narrador opcional.

### Financeiro (atual)

System prompt diz:

> IMPORTANTE: O fluxo de caixa numérico (cashFlow) já foi calculado deterministicamente pelo backend.
> Você NÃO precisa recalcular valores. Seu papel é QUALITATIVO

A LLM hoje só replica o cashFlow recebido e gera `alerts` em texto. Pode virar 100% código.

## Arquitetura proposta

```
shared/agents.ts
  → ComercialOutput, FinanceiroOutput (sem mudança)

server/services/
  comercialCalculator.ts (novo)   → calcula BDI ajustado + preço final (determinístico)

server/agents/index.ts
  → ComercialAgent, FinanceiroAgent passam a chamar essas funções

```

**Opção recomendada:** remover as classes de agente e fazer o router chamar as funções diretamente. Reduz indireção. Mantém a posição no array `AGENT_ORDER` para preservar a UI de progresso.

## Implementação — `comercialCalculator.ts`

```ts
import type { ComercialInput, ComercialOutput } from '../../shared/agents';

const BDI_PRESETS: Record<string, number> = {
  reduzido: 15,
  padrao: 25,
  majorado: 35,
};

export interface CompanyBdiSettings {
  bdiPercentual: number;
  lucroPercentual?: number;
  adminCentralPercentual?: number;
  despesasFinanceirasPercentual?: number;
  riscosPercentual?: number;
}

export interface ComercialContext {
  projectBdi?: number;
  bdiPreset?: keyof typeof BDI_PRESETS;
  companyBdiSettings?: CompanyBdiSettings;
}

export function computeComercial(
  input: ComercialInput,
  context: ComercialContext = {},
): ComercialOutput {
  const custoBase = input.totalDirectCost + input.totalIndirectCost;

  const baseBdi =
    context.projectBdi ??
    (context.bdiPreset ? BDI_PRESETS[context.bdiPreset] : undefined) ??
    context.companyBdiSettings?.bdiPercentual ??
    25;

  const ajustes: string[] = [];
  let bdiAjustado = baseBdi;

  if (input.fiscalRisk === 'high') {
    bdiAjustado += 5;
    ajustes.push('+5% por risco fiscal alto');
  }
  if (input.logisticsComplexity === 'high') {
    bdiAjustado += 5;
    ajustes.push('+5% por complexidade logística alta');
  }

  const bdiDecimal = bdiAjustado / 100;
  const totalBdiAmount = custoBase * bdiDecimal;
  const finalPrice = custoBase + totalBdiAmount;

  const justification = ajustes.length === 0
    ? `BDI base de ${baseBdi}% aplicado sem ajustes adicionais.`
    : `BDI base de ${baseBdi}% com ajustes: ${ajustes.join(', ')}. BDI final: ${bdiAjustado}%.`;

  // pricePerUnit: agrupa por unit dos budgetItems
  const pricePerUnit: Record<string, number> = {};
  if (input.budgetItems) {
    const totalQtyByUnit: Record<string, number> = {};
    for (const item of input.budgetItems) {
      totalQtyByUnit[item.unit] = (totalQtyByUnit[item.unit] ?? 0) + item.quantity;
    }
    for (const unit of Object.keys(totalQtyByUnit)) {
      const qty = totalQtyByUnit[unit];
      pricePerUnit[unit] = qty > 0 ? finalPrice / qty : 0;
    }
  }

  return {
    baseBdi: bdiDecimal,
    adjustedBdi: bdiAjustado / 100,
    bdiJustification: justification,
    totalBdiAmount,
    finalPrice,
    pricePerUnit,
  };
}
```

## Implementação — `financeiroAnalyzer.ts`

```ts
import type { FinanceiroInput, FinanceiroOutput } from '../../shared/agents';

export function analyzeFinanceiro(input: FinanceiroInput): FinanceiroOutput {
  const cashFlow = input.cashFlow ?? [];
  const alerts: string[] = [];

  // Exposição máxima
  const minBalance = cashFlow.length > 0
    ? Math.min(...cashFlow.map(c => c.balance))
    : 0;
  const maxExposure = minBalance < 0 ? Math.abs(minBalance) : 0;

  // Adiantamento sugerido (modelo 40/60 padrão)
  const suggestedAdvance = input.totalPrice * 0.4;

  // Margens
  const grossMargin = input.totalPrice - input.totalCost;
  const grossMarginPercent = input.totalPrice > 0 ? (grossMargin / input.totalPrice) * 100 : 0;
  const netMargin = grossMargin; // impostos não vêm neste input — o Auditor recalcula
  const netMarginPercent = grossMarginPercent;

  // Regras de alerta
  if (maxExposure > 0) {
    const week = cashFlow.find(c => c.balance === minBalance)?.week;
    alerts.push(`Exposição máxima de R$ ${maxExposure.toFixed(2)} prevista${week ? ` na semana ${week}` : ''}. Considerar medição intermediária.`);
  }

  if (grossMarginPercent < 10 && grossMarginPercent >= 5) {
    alerts.push(`Margem bruta baixa (${grossMarginPercent.toFixed(1)}%). Revisar custos antes de fechar a proposta.`);
  } else if (grossMarginPercent < 5) {
    alerts.push(`Margem bruta crítica (${grossMarginPercent.toFixed(1)}%). Projeto inviável sem revisão.`);
  }

  if (input.paymentTerms?.toLowerCase().includes('30 dias') || input.paymentTerms?.toLowerCase().includes('60 dias')) {
    alerts.push('Prazo de recebimento estendido. Considerar capital de giro suficiente para cobrir o ciclo.');
  }

  return {
    cashFlow,
    maxExposure,
    needsAdvance: true,
    suggestedAdvance,
    alerts,
    grossMargin,
    grossMarginPercent,
    netMargin,
    netMarginPercent,
  };
}
```
